What It Builds

The project includes codebase ingestion, OpenAI embedding with retry logic, persistent local ChromaDB retrieval, a Groq-backed LangChain generation chain, an automated pytest coverage harness, and a Gradio demo app.

Run Locally

The full source is available on GitHub. Install dependencies with pip install -r requirements.txt, set OPENAI_API_KEY and GROQ_API_KEY, build the vector store, then run python app.py or python scripts\generate_test.py "def default_headers() -> CaseInsensitiveDict".

Evaluation

The first automated 50-function run produced a 8.0% pass rate and exposed useful failure categories for the next iteration: syntax, assertion, import, and other runtime failures. The obvious next step is a repair loop that feeds pytest output back to the model.
